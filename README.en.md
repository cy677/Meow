# Meow · Family Growth Garden

This fork now provides a local family points-pet application for ages 3–10, with parent-selected age modes, six parallel growth categories, documented award criteria, SQLite records, and the original interactive kitten.

The maintained functional, installation, migration and testing documentation is the [Chinese README](README.md). The former generator-only README is no longer applicable to this fork. These product categories and point values are not a clinical or developmental assessment.
