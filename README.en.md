# Meow · Family Growth Garden

This fork now provides a self-hosted family points-pet application for ages 3–10, with parent-selected age modes, six parallel growth categories, documented award criteria, SQLite records, and the original interactive kitten.

The maintained functional, installation, migration and testing documentation is the [Chinese README](README.md). The former generator-only README is no longer applicable to this fork. These product categories and point values are not a clinical or developmental assessment.

Based on [Meow-Generator](https://github.com/ringhyacinth/Meow-Generator). Required Notice: Copyright 2026 Simon_阿文 (Simon Lee) and Ring Hyacinth (海辛).

Business records live in SQLite on the computer or server running Node.js, not the iPad. Camera photos are composed in browser memory, never uploaded or stored in a web album, and saved through the device system menu by the user. See [Photo V1](docs/photo-v1.md).
