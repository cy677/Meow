# 动画优化分支的更新与验收

## 提交与使用

分支：`feature/cat-motion-refinement-20260924`。功能实现提交为 `88388c83117ac03e52df3c43ee9ba80fb40e4e08`，收尾验证提交为 `d455d1e1af713f3670eb7a41625fccc17c2ba1a3`。本次在该分支补齐可复用测试命令与交付说明，没有合并到 main，也不使用旧的独立叶猫模型分支。

在已有 Meow Git 工作目录中，先保存本地修改；工作区不干净时不要强制切换。停止服务并备份配置文件指定的数据目录，再执行：

```sh
git fetch origin
git switch feature/cat-motion-refinement-20260924
git pull --ff-only
npm ci
npm run pet:build
npm run pet:start
```

仅查看原版编辑器使用 `npm run dev`。已经部署的生产服务仍应沿用原启动器或进程管理方式，在构建完成后重启。更新时保留家庭配置、证书和数据库目录，不执行数据重置脚本。源码包不是编译后的 Ubuntu 增量更新包，不要把补丁交给服务器更新器直接安装。

在原编辑器或家长创作页选择「体型 → 外观 → 小猫外观 → 叶猫外观（原版身体与动作）」。坐下等仍选择原版动作；没有单独口型选项，开闭口自动随叫唤、仰头叫、咬咬、扑接及伸懒腰的阶段变化。行走、站立、坐下等保持闭口。旧作品的口型字段仅兼容读取，不控制动画；新作品保存时移除该字段。

## 可复用测试命令

```sh
# 聚焦本次修改的数值与参数兼容测试
npm run test:motion-refinement
# 全部业务测试，以及原动作、抚摸形变回归
npm run test:pet
npm run test:motion
npm run test:poke
# 两套生产构建
npm run build
npm run pet:build
# 实际编辑器及生产家长/儿童页面验收
# 仅测试环境需要 Playwright 和 Chromium，生产运行不依赖它们。
npm run test:motion-refinement:browser
```

浏览器测试复用原编辑器和原家庭服务，不创建另一套叶猫查看器。CI 在临时目录安装浏览器工具，避免改变生产依赖或 package-lock.json；本地使用自备 Chromium 时可以通过 `CHROMIUM_PATH` 指定可执行文件。
