## 迁入功能

保留 19 骨固定蒙皮与原 14 个动作，加入 `scratch`、`paw`、`climb-up`、`climb-down`、`mantle`、`stretch` 六类局部关节曲线。统一动作注册、骨骼与根姿势混合、脚本校验、优先级、排队、中断续播、暂停与停止，并保留语义事件和目标槽位。

家长预览与儿童首页继续共用运行时。需要物体目标的动作不进入无目标随机播放池。这里没有新增真正爬架、接触力、IK、寻路或趴下睡眠动画，完整边界和调用方式见 [动作框架说明](cat-motion-stage1.md)。

## 更新使用

停止原服务，在安装目录外备份实际数据目录和配置。切换新迁移分支，执行 `npm ci --ignore-scripts`、`npm run pet:build` 后按原方式启动。不要执行数据清除命令，也不要用默认配置覆盖自己的 `pet-settings.json`。首次切换有本地文件冲突时，应先保存本地修改，不要使用 `reset --hard` 或强制覆盖来隐藏问题。

本次只提交迁移分支和 PR，不执行 main 合并或公网部署。
