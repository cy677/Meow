# 叶猫模型 v1

依据提供的多视图角色设定图制作，作为 **独立角色模型** 接入 Meow；原版小猫仍是默认角色。没有覆盖原猫组件、增加数据库迁移或修改现有积分与兑换记录。

## 打开与选择

在项目目录执行 `npm ci` 后：

- `npm run dev`：打开原版编辑器，在“体型 → 角色模型”选择“叶猫（参考图造型）”。
- `npm run pet:dev`：沿用服务输出的访问地址。家长端进入原版创作编辑器后，同样在“角色模型”中选择叶猫，可保存为作品奖励或草稿。
- 独立模型检查页为上述积分宠物服务的 `/leaf-cat.html`。生产部署前执行 `npm run pet:build`。该页不读取账户、不产生积分变化。

旧版作品没有 `characterModel` 字段时，恢复为原版小猫。新作品通过现有预设白名单保存 `characterModel: "leaf-cat"`，不需要维护另一份账户数据。

## 造型与组件

复用 `src/sdf.js` 的球体、圆锥与平滑并集网格化内核、`buildCat` 入口，以及原有皮肤骨骼绑定和动作系统。新增代码位于 `src/models/leafCat/`，没有复制一个平行的游戏运行时。

| 文件 | 职责 |
| --- | --- |
| `config.js` | 参考配色、比例默认值和边界 |
| `geometry.js` | 带厚度的圆润叶片、耳片、沿头部曲面投影的矢量图案、封闭卷尾 |
| `body.js` | 融合的头身、腿爪、尾部及连续骨骼权重属性 |
| `details.js` | 耳内片、面纹、粉色眼睛、鼻口獠牙、颊毛、双层颈饰和四足肉垫 |
| `buildLeafCat.js` | 返回兼容原版 `buildCat` 的 Three.js Group |
| `exportLeafCat.js` | 19 骨骼 GLB 与原有动作的关键帧烘焙 |
| `frameCharacter.js` | 切换角色时一次性重新适配相机，不干扰后续手动旋转 |

面纹与眼睛是贴合实际头部曲面的几何网格，不是把参考图作为平面贴片。叶耳、颈饰和尾巴有真实厚度。颈饰跟随上脊骨、五官与耳朵跟随头骨、四足肉垫跟随对应足骨。皮肤权重在躯干、头颈与四腿交界处连续过渡。

为保持头部曲面贴合，原有绑定模块新增可选的 `rigBodyBlend`、`rigBone` 与 `rigidFaceSurface` 支持；没有这些字段的原版猫沿用原处理。抚摸形变支持可选局部原点偏移，原版默认偏移为零。

## 动作和导出

独立页支持鼠标/触控旋转、七个观察角度、五组比例参数、颈饰显示和网格检查。动作使用项目原有时钟与骨骼实现，检查页提供待机、行走、轻拍、跳跃、抓挠，不是整体上下移动的替代动画。

“下载 GLB 模型”导出一个新建模型，不会中断正在运行的角色。导出带 19 骨骼及 `idle`、`walk`、`paw`、`jump` 四段已烘焙动画。可用 Blender 的 glTF 2.0 导入器，或 Three.js 的 GLTFLoader 打开。静态导出保留骨骼但不含动画。运行时的更多动作没有全部写入 GLB。

## 已知边界

本版是按参考图制作的程序化重建，不是官方原始网格或逐像素复刻。默认比例接近参考图，可继续调整头身、圆润度、耳、腿和尾部。面部及身体使用固定参考配色，原版毛色/眼色选项不改变叶猫配色。原版“面包趴”、猫窝适配等夸张静态形变暂未重做，叶猫编辑时隐藏这些姿势，已有骨骼动作继续可用。

独立预览、GLB 导出与原版编辑器集成都属于本次范围；没有增加猫爬架寻路、物理攀爬、新积分机制或独立语音控制。高质量模型约十二万三角形，存在 draft 网格；没有将其声明为已经完成真机 iPad 性能验收。

## 验证

```sh
node --test pet/tests/leaf-cat.test.mjs
npm run test:pet
node scripts/test_soft_poke.mjs
npm run pet:build
npm run build
# 需要安装 Playwright / Chromium 的浏览器测试环境
node scripts/leaf-cat-review.mjs
```

新增测试覆盖封闭几何、有限坐标、参数上下界、19 骨骼归一化权重、部件附着、20 段运行时动作、旧预设回退和四段导出动画。浏览器回归使用内存数据库，检查生产构建的预览页、双 GLB、家长创作编辑器中的切换与动作绑定，以及保存作品不改变儿童状态。未连接操作者正在使用的服务器或数据库。

本项目原有许可证与署名保留。参考图角色的相关权利不会因程序化重建而转为公共领域；本次新增实现不扩大项目或参考角色的商业授权。
