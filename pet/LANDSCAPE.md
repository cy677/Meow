# 孩子页：横屏 iPad 小猫主窗口

本次布局替换之前的孩子页竖向仪表盘；家长页面、积分服务、局域网端口和本地数据库不变。

## 小猫优先

小猫画布铺满浏览器可用内容区，使用动态视口高度适应浏览器工具栏。不再保留上方三块统计卡片、侧边成长栏或下方奖励长列表。只保留昵称、积分、家长/退出入口和底部悬浮按钮。按横屏 iPad 设计，不提供独立竖屏排版，不强行锁定屏幕方向，不要求系统全屏权限。

设计/测试视口是 1024×768、1180×820、1366×1024，以及浏览器工具栏缩小后的 1024×600，单位是 CSS 像素，不是设备物理像素。是否通过以对应提交的实际检查结果为准。

## 内嵌分页选择

“奖励小屋”和“我的收藏”在当前页面打开同一个内嵌弹窗。弹窗有发现奖励、我的收藏和成长记录三个页面，不开新窗口、不跳转页面。

奖励每页 6 项（3 列×2 行），支持全部/花色/外形/眼睛/姿态/互动筛选和上一页、下一页。切分类或页面时从第一页开始；后台加分不会打断正在浏览的奖励页码。成长记录每页 5 条，保留查询、类型筛选、当时奖励参数和前后翻页；家长的完整历史仍采用加载更早记录，不变为五条分页。

兑换仍先显示确认窗口，取消不扣分。兑换成功后留在列表中选择是否使用。换装或播放动作成功后自动关闭选择弹窗，让孩子直接看到小猫。关闭按钮、Escape 或遮罩上的完整轻触可返回小猫；拖动后松手不会误关闭。浏览器原生模态焦点限制避免操作穿透到小猫。

关闭弹窗不重建三维画布；普通观看角度保留。实际换装仍由原渲染器重建相应模型。弹窗出现时倾斜暂时让位，关闭后以当前握姿重新校准，不重新申请权限。翻页、查看历史或取消不会写入积分/拥有权。

## 更新和启动

先停止旧服务并备份整个 `pet/data/`，更新时不要删除它。在工程根目录执行：

```powershell
npm ci --ignore-scripts
npm run pet:build
npm run pet:lan
```

Node.js 22.16+。孩子在 Pad 浏览器输入终端显示的 `http://实际服务器IP:8792/`；家长页为 `/parent.html`。启动后刷新旧页面以加载新版。包含已编译 `pet/dist` 的运行包只需 `npm run pet:lan`。

积分、理由、兑换内容和预设仍保存在 `pet/data/pet.sqlite`，不会保存在 Pad 浏览器里另起一套账本。程序不改系统防火墙、不上传家庭数据。

触摸正常使用 HTTP；倾斜传感器仍需 Pad 信任的 HTTPS 与主动授权。HTTPS/IP 证书和 8793 端口设置继续见 `PAD.md`，不存在关闭安全保护的要求。

## 验证

新增 `tests/reward-pages.test.mjs` 和 `tests/browser-landscape.mjs`；原三套浏览器流程已改为通过可见的弹窗/分页选择奖励，不绕过界面。验证包括完整目录无漏项、分类/收藏、下一页、实用高度下按钮可达、嵌套确认取消、换装/动作回到原画布、历史前后翻页、后台加分保留页码和焦点、弹窗关闭与权限回归。浏览器自动化不等同于实体 iPad Safari 验收。
