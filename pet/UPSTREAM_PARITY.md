# 原版功能对照

2026-09-18 对照本机 `Meow-Generator-main`。首页直接运行原版页面和 `src/main.js`；没有额外的原版互动入口。原版源码、素材、动画、署名与许可证均保留，功能适配集中在 `pet/`。

| 原版内容 | 当前入口与解锁规则 |
| --- | --- |
| 14 段骨骼动画、状态机、键盘自由行动 | 默认免费；首页动作选择与触摸方向键，键盘直接响应 |
| 揉捏、提起、回弹、眨眼、视线、旋转缩放 | 首页直接互动，默认免费 |
| 随机对白 | 原版自动对白默认运行；功能菜单可立即触发 |
| BGM、光照球、晴天/阴天/雨/雷/鱼雨 | 免费功能菜单，保留原版调节与天气音效 |
| PNG 收藏卡、换皮肤、收藏编号与稀有度 | 免费功能菜单“拍照与分享卡” |
| GLB、Codex 参数 JSON、参考 PNG、指令与样机 | 免费功能菜单，复用原版导出模块 |
| 全部 11 种花色、7 种普通姿态、眼色与异瞳 | 原有预设按积分解锁，初始造型免费 |
| 六类容器、随机猫窝、容器软体 | 猫窝预设；家长可调参数并保存为作品奖励 |
| 身体尺寸、毛发、自定义花色、眼睛设置 | 家长参数面板调整后保存为作品奖励 |
| 垫子、木地板、线条、捏猫手感、地面影子、身上阴影 | 家长参数面板调整后保存为作品奖励；捏猫动作本身免费 |
| 毛线球、球、鱼、鸭子、软垫物理交互 | 首页原版场景，支持原版抓取与投掷 |
| 随机小猫 | 仅家长可随机生成，保存固定结果作为积分奖励 |
| 中、英、日界面、移动端控件 | 原版场景保留，首页适配平板布局 |

旧余额、成长分、拥有权、装备和流水保持不变。参数面板和随机生成统一由家长管理，旧功能权限卡退出目录展示；免费动作与功能不能被重新设为收费。家长草稿不影响孩子，作品需解锁并使用。

本次验证覆盖：零积分首页加载、原版动作、键盘、触摸、音乐、光照、天气、随机对白、家长作品与草稿隔离、积分解锁、固定结果复现、奖励逐步揭晓、分享卡 PNG、GLB、Codex JSON 和参考 PNG、平板布局。接口测试包含旧库升级、余额和流水保留、导入后免费规则，以及家长写入权限。

检查命令：`npm run test:pet`、`npm run pet:build`、`npm run build`。`pet/tests/browser-creation.mjs` 覆盖家长作品、草稿隔离、奖励揭晓和孩子入口；`pet/tests/browser-studio.mjs` 包含首页零积分检查及原版参数、导出回归。
