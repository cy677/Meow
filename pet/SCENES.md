# V6 本地场景奖励：实现、使用与边界

## 这次做了什么
积分、理由、兑换快照、装扮、场景预设和套装全部仍在本机 `pet/data/pet.sqlite`。Pad 使用同一服务的 IP，不在浏览器另建账本。没有云存储、远程模型、外部纹理或统计上报。

首次启动一次性补入48项记录：8个初始槽位、37个场景物品、3个套装。迁移与初始拥有权写入同一个 SQLite 事务，不改旧积分、旧价格、猫外观或历史。再次启动不会重新覆盖。升级前必须停服备份并保留整个 `pet/data`。

## 实际接入清单
| 类别 | 原版来源 | 本版接入 |
|---|---|---|
| 木地板 | src/main.js 的 drawWoodFloor | 提取原算法，8套原版配色；底色、接缝、木纹、板宽、密度、方向 |
| 地毯 | src/rug.js | 7种原版绘制器：披萨、棋盘、条纹、圆心花、野餐格、彩点、太阳；固定种子、大小与方向 |
| 容器 | src/container.js、src/catBuilder.js | 纸箱、花盆、藤篮、搪瓷盆、小水桶、布艺箱；旁置或真实 containerCrouch 入窝造型 |
| 软垫 | src/toys.js | 原版软垫猫窝，放置在小猫身边 |
| 玩具 | src/toys.js、cannon-es | 毛线球、皮球、小鱼布偶、小鸭子及混合组合；实际刚体与拖拽约束 |
| 天气 | src/weather.js | 多云、细雨、雷雨、小鱼雨；晴天为默认；云漂移、雨滴更新、小鱼刚体下落 |
| 灯光 | 原版 Hemisphere/Directional 光源配置 | 色温配色、主灯/环境光强度、方位和仰角 |
| 镜头 | 原版 PerspectiveCamera/OrbitControls | 初始方向、仰角、视角、距离；保留触摸与倾斜 |
| 雾效 | 原版 THREE.Fog | 雾色、开始和结束距离，独立装备槽位 |
| 动画 | V5 已接入的原版19骨/14片段 | 保留真实蒙皮与连续脚本；入窝静态模型表演后恢复 |

草地、雪、飘叶、逗猫棒、写实肌肉和自动寻路不是本次核对到的原版能力，本版不以它们冒充现有功能。灯光、相机和雾是渲染配置，不应全部称为独立“建模”。

## 家长与孩子怎么用
家长在奖励预设中筛选类别，新增、复制或修改，拖动滑块 / 选择颜色，右侧预览实际场景，点击保存才写入本地。
选择“场景套装”可为每个场景槽位挑一件目录中的物品，不要求先让孩子购买。已有套装的成员列表不能直接改变，请复制成新套装；名称、说明和积分价格可调整。

孩子在横屏分页弹窗的“场景布置…”下拉框选择地板、地毯、猫窝、玩具、天气、灯光、镜头、雾效或套装。兑换后永久拥有，可装备或卸下；卸下恢复家长配置的该槽位初始预设，不退还积分，也不删除拥有权。

套装价格是整套固定价格，**不按已拥有部分自动折价**，确认框有说明。一次购买原子地取得套装及其成员，重复请求不会再扣款；装备套装一次应用它包含的所有槽位。单独换装或卸下一项后取消“整套正在使用”标记，其他槽位不变。套装没有包含的槽位保持原样。

预览、摸猫、拖玩具、调整视角、整理玩具都不产生积分操作。价格为0且达到门槛的场景奖励自动赠送，但不会强制改变小猫当前房间。

## 容器与骨骼联动
“放在身边”只布置容器，不改小猫网格。“进入容器”调用原版 containerCrouch 和容器开口参数，显示同花色/体型的小猫入窝造型，保存的猫姿态奖励不变。
播放四足骨骼动作时暂时切换站立绑定，容器随入窝模型一起隐藏，动作结束恢复入窝。两套静态拓扑之间仍是显示过渡，不声称小猫能连续跳进任意容器。软垫仅旁置，没有虚构入窝动画。

## 触摸、物理与声音
单指抓住实际可见玩具后拖动，由原版 Cannon 点对点约束移动，松手继续落地/滚动；非玩具区域仍旋转小猫视角。双指或取消触摸、打开弹窗、切后台、退出时释放玩具约束。整理玩具将当前玩具按固定种子摆回原处。
最多同时5件可抓取玩具。皮球只有1个原版变体，小鱼/小鸭各3个，毛线球5个；表单与服务端都检查数量，不生成未声明变体。
玩具与地面、彼此、猫的近似球形碰撞体、旁置容器和场景边界碰撞；猫的碰撞体是近似体，不是逐三角面精确碰撞。
拖动后的瞬时物理位置不写入积分数据库，刷新会按已保存的摆放种子恢复；**拥有权、物品配置、数量、种子和装备状态**会一直保留。

雨声/雷声默认关闭，必须点“开启环境音”；天气效果由已装备天气决定，退出或切后台停止。低幅慢闪电默认关闭，并服从减少动态效果设置。声音仅本地合成，不申请麦克风权限。
减少动态效果模式下不自动播放天气运动；实体 iPad 的硬件和帧率仍需实机验收。

## 数据和接口
`GET /api/state`、`GET /api/pet/config` 在原字段基础上新增 `sceneParams`，包含八个完整场景槽位。`params` 仍只包含猫参数；换木地板不重新生成猫网格，也不重置动作。
`POST /api/equip` 继续使用 `{rewardId}`，先核验拥有权；`POST /api/unequip` 新增 `{slot}`，仅允许八个场景槽位。
家长仍使用带版本的 `/api/parent/presets` 或完整目录接口。场景和套装参数有严格字段/枚举/数值限制，禁止网络地址、脚本及嵌套套装。
新的套装购买记录保存当时完整成员参数快照；后来改物品外观不会改写旧账。旧版缺失快照不伪造补填。

## 生命周期和性能
场景配置与猫参数分离；场景模块延迟创建，只在对应槽位改变时更新。地毯/木地板复用纹理，玩具池不随每次轮询重建，换猫窝显式释放几何与材质。关闭预览释放其物理、纹理、声音和监听器。
小鱼雨数量单独限制到最多约11条物理鱼，不把原作224条上限直接照搬到平板。程序当前会保留已经初始化但隐藏的模块以便再次切换；退出预览或页面销毁才全部释放。
原始编辑器 `src` 文件未修改；共享渲染器的来源和许可证继续保留，原项目非商业条款不变。

## 启动与验证
源码版本在Node.js 22.16+运行：
```
npm ci --ignore-scripts
npm run pet:build
npm run pet:lan
```
含已构建页面的运行包只需最后一条。仍是HTTP/IP 8792，可信HTTPS/IP 8793；不要公开映射端口，保护本地数据和私钥。

`npm run test:pet` 覆盖场景升级、数据重启、参数拒绝、套装事务/快照/权限、卸下、零价门槛。
`pet/tests/browser-environment.mjs` 用真实编译页面验证家长表单、孩子兑换及触摸、全部场景变体、入窝与动作恢复、资源增长边界和横屏分页。原有五组浏览器回归保留。
是否通过以实际测试日志为准，不因脚本存在就宣称全部通过。
