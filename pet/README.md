# 原版完整移植与成长解锁

原版逐项对照见 [UPSTREAM_PARITY.md](UPSTREAM_PARITY.md)。

孩子页面的“原版互动”已接入 `Meow-Generator-main` 的完整运行程序，使用同一份 `src/` 模型、材质、骨骼、软体交互、场景、音频和导出模块。原作文件保持不变，通过积分版构建适配器接入登录和解锁；运行时不依赖另一个源码目录或原版开发服务。

基础触摸、揉捏、提起回弹、眨眼、视线与视角操作免费。普通小屋也使用完整质量模型和真实触摸形变。原版互动在未完全解锁时使用已装备的小猫和场景参数，并只列出已拥有的原版动作；小屋仍负责奖励兑换、脚本组合及自定义场景布局。

启动时在原有场景迁移之后，一次性补齐缺少的全部 11 种花色、7 种普通姿态、8 种单色眼睛及原有异瞳、14 个源动画和组合动作。容器姿态通过已有 6 类猫窝奖励使用。体型、毛发、自定义花色滑块扩大到原版完整范围，不覆盖原有奖励的 ID、价格、门槛、参数、积分或历史。

“原版功能”分类新增键盘自由行动、拍照与分享卡、GLB / Codex 导出、背景音乐，以及“原版完整创作室”。默认完整创作室门槛为累计 300 分、兑换费用 200 分，家长可修改；兑换时一次获得当前目录全部奖励，并开放原版全部参数面板、随机生成、渲染排线、容器软体、天气和导出功能。它是可选的一次性整包解锁；普通奖励仍可逐项兑换。键盘自由行动包含原版状态机动作，并提供平板触摸方向键。

家长在“奖励预设 → 原版完整参数”中直接使用原版编辑界面。点击“保存完整方案”把小猫、随机种子、地板、垫子、光源方向、天气、排线、触摸手感及镜头保存到本地 SQLite；完整解锁的孩子下次进入原版互动时加载。预览不改变当前装扮，孩子的临时创作不覆盖家长保存方案。保存带独立版本检查；过期会话必须重新登录。

接口：`GET /api/studio` 返回孩子已授权的能力，未解锁完整创作室不返回家长完整方案；`GET /api/parent/studio` 和 `PUT /api/parent/studio` 用于读取、保存方案，写入格式为 `{preset, expectedRevision}`。方案字段有服务端白名单和范围验证。目录上限为 512 项，为原有自定义目录和自动迁移留出空间。

原版的实验性骨骼、容器软体及 Codex 导出保持原有行为；这里不将原作实验功能描述为新增的成熟功能。来源及非商业许可证、第三方动画署名继续保留。

# Meow 积分小猫（本地版）

一户家庭、一个孩子的积分宠物。新增功能集中在 `pet/`，复用原作三维小猫，不修改原编辑器。家长填写理由并加分，孩子在横屏全窗口小猫页面中兑换、收藏和使用奖励。

## 本次骨骼动作更新

已接入原作 **14 个片段、19 根骨骼和 555 个源帧**，替代旧版跳跃/转圈的整体变换。家长页点击“添加骨骼动作奖励”可加入 11 项示例，也能在互动预设里选择“自定义动作脚本”，用表单编排最多 8 步。旧积分、奖励 ID、价格和拥有权不重置，不在启动时自动覆盖奖励目录。

动作使用真实关键帧蒙皮，片段之间混合骨骼姿势，停止时平滑回到待机。普通行走和奔跑展示原地步态；转圈使用行走骨骼加小范围闭合路径。特殊静态造型播放时临时淡入站立绑定模型，结束后恢复；这是不同网格的显示过渡，不是静态形态间的骨骼变形。叫唤片段没有附带新猫叫音频。

详细说明：[骨骼动作与脚本](MOTION.md)；[横屏孩子页与分页弹窗](LANDSCAPE.md)；[Pad、触摸、IP 和 HTTPS](PAD.md)。

## 数据全部保存在本地

积分余额、累计成长积分、每次加分理由、兑换流水和当时奖励快照、已拥有奖励、当前装扮、家长参数预设和动作脚本，全部保存在运行服务电脑的 `pet/data/pet.sqlite`。不是浏览器缓存，不依赖云端账户，也不自动上传到 GitHub。内存数据库仅用于测试。

关闭页面、重新登录、清理浏览器数据或重启服务不会清除进度。家长页“记录与设置”显示实际数据库路径；`MEOW_DATA_DIR` 可指定自定义数据目录。Pad 访问同一服务，数据仍在服务器电脑，不会两台设备各记一套。

首次建库从 `rewards.json` 读取初始目录，此后以本地数据库为准，重启不会用初始 JSON 覆盖家长的设置。

## 启动与更新

Windows 可直接双击项目根目录的 `一键启动.cmd`。启动配置、IP/公网端口和数据重置操作见 [运行说明](../运行说明.md)。双击 `清除数据.cmd` 会在停服状态下备份并重置全部账户和进度。

需要 Node.js 22.16 或更高版本。源码根目录执行：

```sh
npm ci --ignore-scripts
npm run pet:build
npm run pet:lan
```

孩子页面：`http://服务器IP:8792/`；家长页面：`http://服务器IP:8792/parent.html`。终端列出实际网卡地址。包含已编译 `pet/dist` 的运行包只需执行最后一条命令。只在本机使用时可用 `npm run pet:start`，默认监听本机。

首次启动终端打印一次性初始化口令。家长输入口令，设置 6–12 位数字密码、4–12 位数字孩子进入码及昵称；没有默认密码，两种码不能相同。家长登录 15 分钟后过期，同一浏览器交给孩子前请主动锁定家长页。

更新前停服并备份，更新时保留整个 `pet/data/`。旧库按需增量迁移，不清积分、不重置预设。不要运行 `git clean -fdx`，它会删除被忽略的数据目录。`MEOW_PORT` 可改端口。

开发模式 `npm run pet:dev`；原作编辑器仍用 `npm run dev`，默认 8791，互不接管。积分版需要常驻 Node 服务，不能只放到 GitHub Pages；服务器停止或休眠时 Pad 无法连接。

HTTP 只用于可信家庭网络，不要直接映射公网。触摸可通过 HTTP/IP 使用，方向传感器需要可信 HTTPS 与主动授权。`npm run pet:lan:https` 默认 8793，使用 `MEOW_TLS_CERT`/`MEOW_TLS_KEY` 指定设备信任且包含实际 IP 的证书与私钥；仍不要求购买域名。证书缺失或无效不降级 HTTP。反向代理可设置 `MEOW_ORIGIN` 并保留 Host。具体防火墙、证书信任和传感器边界见 PAD.md，程序不自动修改系统设置。

## 理由与历史

“日常加分”必须填写理由。空白或缺失理由在页面和服务端均被拒绝，快捷理由按钮只辅助填写，不自动加分。负数用于更正余额，同样必须写原因且不能透支。

家长和孩子都可以按理由或兑换名称搜索，并按加分、更正、兑换、礼物和预设修改筛选。家长加载更早记录，孩子在弹窗中每页 5 条前后翻页；不只保留最新 100 条。

新的兑换与礼物保存当时奖励名称、价格、门槛和参数/脚本快照，后来修改预设不改写旧记录。旧版未保存的历史参数不伪造补填，保留其理由、ID 和时间，并注明缺少旧参数。

## 家长预设编辑

“奖励预设”中可新增、调参数、复制，支持地板、地毯、猫窝、玩具、天气、灯光、镜头、雾效、场景套装，以及花色与自定义配色/条纹，体型与毛发，眼睛，特殊静态姿态，以及骨骼动作/连续脚本。使用滑块、下拉框、颜色和数值表单，不要求手写 JSON。

预览使用默认小猫叠加当前参数，动作可试播。预览不扣分，不修改孩子装扮或本地目录；点击“保存到本地”才写入。关闭未保存草稿会提示放弃。

解锁积分是累计门槛，兑换费用是实际扣款。例如累计门槛 50、费用 0，达到 50 自动送出；门槛 50、费用 20，达到门槛后由孩子确认并消耗 20 分。累计成长分不因消费或余额更正减少。已有奖励永久拥有，不重复收费；没有饥饿、断签、死亡惩罚或抽奖。

已有 ID、类别和初始标记稳定不变。修改价格不重新扣款；修改正在使用的预设会更新当前显示，但历史快照不改。两个家长页面并发编辑时使用目录版本检查，409 冲突保留草稿，可读取新目录后重新检查。

初始 JSON 为 20 项，含 4 项免费初始配置；服务启动后自动补齐场景和原版奖励。家长仍可添加自定义脚本或导入整个目录。全新造型或源库没有的动画仍需新增实现。原版六类容器已接入，支持旁置和入窝；配置规则见 SCENES.md。

## JSON 与固定接口

批量目录格式为 `{ "schemaVersion": 1, "rewards": [...] }`；单项预设通过对应接口更新。例：

```json
{
  "id": "my-round-kitten",
  "title": "圆圆小团子",
  "description": "家长为你制作的小猫",
  "category": "shape",
  "cost": 20,
  "unlockAt": 50,
  "params": { "chubbiness": 1.7, "legLength": 0.65 }
}
```

连续动作示例见 MOTION.md，使用 `action: "sequence"` 和 `motion.script`。脚本仅支持受限片段步骤，不执行 JavaScript/URL；表单与服务端共用字段白名单，拒绝额外字段、越界值及原型字段。

| 方法与路径 | 权限 | 用途 |
| --- | --- | --- |
| GET `/api/status` | 无 | 是否已初始化 |
| POST `/api/parent/setup` | 一次性口令 | 初始化凭据与昵称 |
| POST `/api/parent/login`、`/api/child/login` | 相应密码 | `{code}` 登录 |
| GET `/api/parent/session`、`/api/child/session` | 相应会话 | CSRF、到期时间、状态 |
| POST `/api/parent/logout`、`/api/child/logout` | 相应会话 | 注销并吊销令牌 |
| GET `/api/parent/state`、`/api/state` | 家长、孩子 | 积分、拥有权、装扮 |
| POST `/api/parent/points` | 家长 | `{delta,reason,idempotencyKey}` |
| GET `/api/parent/history`、`/api/history` | 家长、孩子 | `q,kind,limit,before`；返回 `entries,total,nextCursor` |
| GET `/api/parent/storage` | 家长 | 实际保存路径、持久化状态、记录数 |
| GET `/api/parent/presets` | 家长 | 完整目录及 revision |
| PUT `/api/parent/presets` | 家长 | `{reward,expectedRevision}`，单项新建/修改 |
| GET/PUT `/api/parent/catalog` | 家长 | 整个目录；写入可加 `If-Match` 版本 |
| PUT `/api/parent/profile` | 家长 | `{childName,petName}` |
| PUT `/api/parent/credentials` | 家长和当前密码 | `{currentPin,newPin?,childCode?}` |
| GET `/api/parent/export` | 家长 | 完整流水、状态和目录，不含密码 |
| POST `/api/purchase` | 孩子 | `{rewardId,expectedCost,idempotencyKey}` |
| POST `/api/equip` | 孩子 | `{rewardId}`，装备已拥有内容或整套场景 |
| POST `/api/unequip` | 孩子 | `{slot}`，卸下场景物品并恢复初始预设 |
| POST `/api/play` | 孩子 | `{rewardId}`，返回已核验动作及 motion（包含可选 script） |
| GET `/api/pet/config` | 孩子 | 当前参数、槽位和允许动作 |

写请求使用 `Content-Type: application/json`、`X-Meow-Client: points-pet`。除初始化与登录外需对应 Cookie 和 `X-CSRF-Token`。外部程序可用 Cookie jar，浏览器默认拒绝跨站。

新加分/购买使用新 UUID 作为幂等 ID，超时重试沿用原 ID 和原内容。积分、拥有权、流水和请求去重在同一 SQLite 事务中提交。服务端按本地价格扣款，expectedCost 只核对确认的价格。历史接口 limit 为每页 1–100。

## 备份、安全与测试

完整备份必须停服后复制整个数据目录；恢复前保留当前副本。家长 JSON 导出是可查阅记录，没有自动恢复导入，不能代替数据库备份。不要把孩子真实记录、密码、私钥或数据库提交公开仓库。

密码使用随机盐 scrypt；角色会话隔离、过期校验、改密吊销旧会话，Cookie 为 HttpOnly/SameSite（HTTPS 另有 Secure）。登录有限速，写接口验证角色、CSRF 和价格。生产只开放构建目录，数据库/源码/证书/私钥不作为静态资源提供。浏览器开发工具能修改本地视觉画面，但不能由此修改后台真实积分或拥有权。

```sh
npm run test:pet
npm run test:motion
npm run pet:build
npm run build
```

Actions 还执行主流程、预设、本地记录、平板、横屏弹窗和实际骨骼动画浏览器回归。结果以实际日志为准，脚本存在不代表测试已经通过。传感器测试为模拟事件；未承诺所有实体 iPad 的帧率、接地效果或硬件兼容性。原版绑定仍为实验性线性蒙皮。
