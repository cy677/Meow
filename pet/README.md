# Meow 自托管家庭应用

本目录是3—10岁小猫成长积分服务。完整功能、启动、升级、隐私、许可及测试说明统一维护在[仓库README](../README.md)，原版单纯生成器说明已替换。

## 最常用操作

从仓库根目录执行 `npm ci`、`npm run pet:build`、`npm run pet:lan`。在可信局域网打开终端显示的地址；家长入口为 `/parent.html`。首次需要终端的一次性口令，再设置家长密码、孩子进入码、年龄和学前/学龄基础/学龄进阶模式。

“日常加分”中选择六类和适龄项目，查看完成条件、允许的帮助、默认分值及理由示例，填写真实理由后确认。支持＋1、＋2、＋3、＋5及仅记录。旧的任意正负分表单已移除。

“目标与项目库”可启用少量目标、编辑自定义项目、设置多日步骤。孩子学龄模式提交后等待家长确认；记录留存规则快照。年龄和模式修改不清空任何既有进度。

“记录与设置”查看家庭记录分布和服务端存储位置；流水可筛选六类与待归类旧记录。历史归类不再次发分，更正误录必须关联原流水并填写原因。

儿童首页保持原版互动小猫，新增“成长花园”内嵌弹窗，以六张等大卡片展示故事，不给心理健康或能力评分。礼物、收藏与原版参数作品机制保持独立。
