# 骨骼动画与连续动作脚本

## 原版已有的能力与本次接入

ringhyacinth/Meow-Generator 的实验性 Motion 模式已有 19 骨 SkinnedMesh、14 个 Mesh2Motion 动作片段、555 个采样帧。该代码和数据已经在本仓库的 src 中，本次复用，不下载新的模型、动画或远程脚本，也不改原编辑器。

来源： https://github.com/ringhyacinth/Meow-Generator ，技术说明见本仓库 docs/mesh2motion_acceptance.md；资产来源和 CC0 说明沿用 third_party 下原有署名。本仓库整体许可证保持不变，CC0 只说明动作源资产，不能推导整个程序都是 CC0。

14 个原作片段：自然待机、警觉、行走、奔跑、潜行、跳跃、落下、坐下、休息姿势、叫唤、咬咬、扑接、仰头叫、侧身倒地。后四足动画源来自 fox/cat 骨架，叫唤等不附带猫叫音频；倒地仅为可选表演，不是积分不足惩罚。

积分版原来的整体上移/旋转已替换为真实源帧驱动的骨骼动画。行走、奔跑、跳跃等会改变多个关节和蒙皮，不只是移动整只模型；正常播放复用固定网格，不逐帧重建 SDF。骨骼旋转采用四元数插值，动作片段间重叠混合，开始、结束、停止和中途切换均衔接当前姿势。

## 家长如何添加奖励

进入家长页的“奖励预设”，点击“添加骨骼动作奖励”，加入 11 项缺失的示例奖励，包括行走、奔跑、潜行、坐下、警觉、扑接、叫唤、仰头叫和三个连续动作。再次点击不重复添加，已有奖励的价格/解锁门槛不覆盖。

已有 jump 和 spin 奖励 ID、积分、拥有权不变，只升级显示实现。转圈现在使用行走骨骼加小范围闭合路径，不再将静止猫直接旋转；普通行走/奔跑在原地展示步态，本版没有自主寻路或满场随机游走。

已有家庭不会在启动时被自动加入一批新奖励。家长可先预览和调整门槛，孩子仍通过原来的本地积分接口兑换，未解锁的完整脚本不能从播放接口取得。

## 连续脚本和参数

内置连续脚本：

- 见面打招呼：警觉、叫唤、坐下。
- 好奇探险：警觉、潜行、行走、坐下。
- 发现与扑接：警觉、潜行、扑接、坐下。

新建“互动动作”奖励，动作选“自定义动作脚本”，可以通过表单添加、删除、上下移动步骤，选择片段、次数、单步速度，设置整体速度、动作幅度和衔接时间。先点“试播动作”，满意后“保存到本地”。

最多 8 步，单步循环最多 4 次，一次性跳跃/坐下片段每步只播一次；总时长受限。片段使用完整源时间范围，过渡重叠会让实际总时长略短于简单相加。整个动作可以随时停止，停止后先混合回待机。

脚本是受限 JSON，不接受任意 JavaScript、URL、eval、嵌套脚本或网络请求。例：

```json
{
  "id": "custom-greeting",
  "title": "我的打招呼",
  "description": "看一看，走两步，坐下来。",
  "category": "trick",
  "cost": 20,
  "unlockAt": 40,
  "action": "sequence",
  "motion": {
    "speed": 1,
    "intensity": 0.85,
    "transition": 0.25,
    "script": [
      {"clip": "idle-alert", "cycles": 1, "speed": 1},
      {"clip": "walk", "cycles": 2, "speed": 1},
      {"clip": "sit", "cycles": 1, "speed": 1}
    ]
  }
}
```

这是一项奖励，不是完整目录。批量导入仍采用原有 schemaVersion/rewards 格式，或使用带 expectedRevision 的单项预设接口。脚本随 motion 保存，因此现有播放接口、本地 SQLite、兑换快照和权限逻辑无需另起一套。

## 静态造型与动态基准

原版完整骨骼基于 standing 四足造型。猫咪面包、香蕉、侧卧等是重新生成的不同拓扑网格，不能假称可以直接做相同骨骼的站起变形。

选用这些静态造型时，播放会通过短暂交叉淡入淡出切换到同花色/体型的站立骨骼模型；动作结束后恢复原静态造型，不修改数据库中的装扮。真正的骨骼片段之间使用姿势混合，不换网格；静态拓扑之间是显示过渡，不是骨骼 morph。

## 数据与运行

积分、必填理由、预设和兑换内容仍在本地 pet/data/pet.sqlite，更新前停服备份并保留。源码更新后运行 npm run pet:build，再 npm run pet:lan。含 pet/dist 的运行包不需重新构建。保持横屏大画布、内嵌分页弹窗和原触摸/倾斜权限。

## 验证与边界

npm run test:pet 包含源片段元数据、时间轴、脚本白名单、权限、磁盘重启与兑换快照测试。pet/tests/browser-motion.mjs 在真实 WebGL 页面中读回骨骼、权重、固定网格和变形采样，并验证家长编排、孩子播放、停止和特殊静态造型恢复。测试是否通过以实际运行日志为准。

原版绑定是实验性的线性蒙皮，极端体型、某些片段仍可能存在脚滑、关节体积或接地细节问题。没有加入写实肌肉模拟、足部实时 IK、自动寻路或新猫叫音频。浏览器模拟测试不是实体 iPad 的帧率或传感器验收，不能承诺所有设备达到固定帧率。
