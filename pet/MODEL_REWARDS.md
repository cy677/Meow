# 第一批模型奖励

此版本加入14项奖励，使用22个 Kenney CC0 模型。模型、调色板纹理和奖励缩略图均随程序发布。普通安装、构建和运行不从素材网站下载内容。

## 使用

儿童打开“礼物与收藏 → 模型礼物”，兑换后点击“换上它”。已拥有物品可反复装备、卸下，不重复收费。新奖励不会自动替换孩子当前的小猫或房间。家长在“奖励预设”里筛选“模型礼物”，修改价格与成长门槛后保存。第一批的模型种类、摆放位置和交互由审核后的代码配置，不接受 JSON 中的外部 URL 或脚本。

小动物播放模型自带的 `idle`、`walk`、`gesture-positive` 等动画。跟随、巡游、飞行路线和小兔轻微起伏由程序控制；不是大模型驱动的动物行为。动物不能作为刚体抓起投掷。

玩具拖动使用现有 Cannon 世界的约束，兼容鼠标和 Pointer Events 触摸。汽车使用刚体车身与简化支撑球，不是独立悬挂、驱动车轮的车辆仿真。积木使用简化碰撞盒，不提供拼接吸附或完整自由搭建编辑器。坡道碰撞由实际模型表面采样得到 Heightfield；桌凳用桌面与支撑腿碰撞体。物体离开边界时回到场景，避免丢失收藏物。

## 模块

- `modelCatalog.mjs`：唯一审核目录、素材位置、价格、物理类型与10个独立装备槽位。
- `models/modelAssets.js`：GLTFLoader、加载缓存、材质与描边、资源回收。
- `models/modelPhysics.js`：车辆/积木/家具的简化碰撞体、坡道高度场。
- `models/modelLayer.js`：场景生命周期、实际动画、手势抓取、灯光、过期异步结果丢弃。
- `store.mjs`：幂等增量安装、拥有权检查、购买与装备。

新模型和原有玩具共用物理世界与渲染时钟，但使用不同实例列表，避免原版玩具数量设置隐藏外部模型。每个小屋最多同时装备10组，彩色积木盒时为19个模型实例；不为每张奖励卡创建 WebGL 上下文。

## 数据与更新

`modelRewardsVersion=1` 仅追加缺少的目录项，不重置任何已有价格、余额、经验、拥有权或装备。模型装备复用 SQLite 的 `equipped` 表，通过审核目录映射独立槽位。升级遇到与用户自定义奖励的 ID 冲突会拒绝该增量事务，不静默覆盖原奖励。

更新前停止服务并备份实际数据目录及本地配置，保留 `pet/data`、证书、`pet-settings.json` 等运行文件。正常执行 `npm ci --ignore-scripts`、`npm run pet:build` 后启动。旧代码不能识别新增模型类别，回退程序时须配套恢复升级前的完整数据库备份。

## 授权与维护

素材来源、下载包哈希、逐文件哈希、内嵌调色板记录见 `../third_party/kenney/manifest.json`。各包原始 `License.txt` 原样保留，模型按 CC0-1.0 使用，项目程序仍沿用 PolyForm Noncommercial 1.0.0。

维护者重建素材：`python3 scripts/import_kenney_models.py`，仅接受固定的官方压缩包与已审核 SHA256。来源版本变化必须人工复核，不能跳过哈希或许可检查。

维护者重建缩略图：安装 Playwright 后执行 `node scripts/render_model_previews.mjs`。缩略图从实际模型渲染，正常构建直接使用仓库内 PNG。

验证：`npm run test:pet`、`npm run pet:build`、`npm run build`、`node pet/tests/browser-models.mjs`。浏览器脚本使用临时内存数据库，不读取家庭数据；自动浏览器结果不能代替真实 iPad Safari 的设备体验验收。
